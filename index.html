Connect your secure database

Before using this portal, the administrator must configure Supabase. Do not enter real records until the security policies are installed.

In the GitHub repository, edit config.js with the Supabase Project URL and publishable/anon key, then run database/schema.sql in Supabase SQL Editor. Never put a service-role key here.

Administrator sign in

Sign in using your administrator email and password, as in the BNHS Wellness Leave Portal.

Your account must have the administrator role in Supabase. No verification email is needed for normal password sign-in.

Staff sign in

Authorized church staff only.

Staff accounts and roles are created by the administrator in Supabase.

Set new password

Enter a new password for your church account.
